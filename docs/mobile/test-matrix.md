# Matriz de homologação mobile

| Perfil | Validar |
| --- | --- |
| Android entrada | FPS, memória, toque, save/load |
| Android intermediário | meta inicial de 60 FPS, orientação, retomada |
| Android alto desempenho | resolução, overdraw, carregamento |
| iPhone compatível | layout, safe area e ciclo de vida |
| 16:9, 19.5:9, 20:9 | HUD, joystick e legibilidade |

Metas de performance exigem medição em dispositivo ou perfil documentado.
