# TerraBela Farm — UI Refatorada v4

Este pacote contém assets individuais de UI recortados corretamente, sem números embutidos, prontos para integração por Claude Code ou outro agente no projeto Godot.

## Garantias deste pacote
- PNGs individuais com transparência.
- Sem cortes incompletos nas bordas dos assets.
- Sem números fixos nos contadores e painéis de runtime.
- Dinheiro oficial padronizado como maço verde com faixa branca.

## Estrutura
- `assets/ui/hud/` — fundos de HUD e painéis.
- `assets/ui/icons/` — ícones, botões e badges.
- `assets/ui/components/` — botões grandes, barras e painéis adicionais.
- `assets/currency/` — dinheiro oficial.
- `reference/` — apenas referência visual, não usar em runtime.
- `docs/` — prompt e mapa dos assets.
