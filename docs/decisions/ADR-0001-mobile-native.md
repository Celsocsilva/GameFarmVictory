# ADR-0001 — Produto mobile nativo

- Status: aceito
- Data: 2026-11-05

Farm Victory será reconstruído como jogo mobile nativo na Godot 4.7.2 Standard, priorizando Android e preservando compatibilidade arquitetural com iOS. Touchscreen, landscape, ciclo de vida mobile, user:// e metas de performance entram na fundação. HTML5, PWA e WebView não são plataformas-alvo.
