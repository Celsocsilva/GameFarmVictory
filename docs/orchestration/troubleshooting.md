# Troubleshooting

- Godot ausente: registrar INCOMPLETE; instalar Godot 4.7.2 e configurar executável.
- GitHub indisponível: preservar task/evidence local e retomar depois.
- Handoff inválido: rejeitar no schema e retornar a REFINEMENT.
- Dependência pendente: manter BLOCKED, sem executar tarefa dependente.
- Interrupção: recarregar orchestration/state/*.json; não criar execução duplicada.
