# Coding standards

- GDScript 4.7.2: nomes snake_case, classes e tipos claros, tipagem explícita em APIs públicas.
- Uma responsabilidade por script; sinais para eventos; nenhuma regra econômica em UI/Animation.
- Validar invariantes antes de mutar estado e retornar erros compreensíveis.
- Testar casos normais, limites, duplicidade, persistência e recuperação.
- Python da orquestração usa biblioteca padrão, type hints quando úteis e sem executar comandos recebidos diretamente de Issues.
