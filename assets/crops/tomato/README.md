# Assets do ciclo do tomate

Os assets estão ordenados pelo ciclo visual da cultura:

1. `SEED` — semente, reutilizada de `assets/seeds/tomato_seed.png`.
2. `SPROUT` — broto recém-germinado.
3. `GROWING` — crescimento vegetativo.
4. `FLOWERING` — floração e início da frutificação.
5. `GREEN_FRUIT` — frutos verdes.
6. `READY_TO_HARVEST` — frutos maduros, prontos para colheita.

A ordem oficial e os caminhos Godot estão em `tomato_growth_cycle.json`. O manifesto classifica os visuais; a lógica de tempo, plantio e colheita deve permanecer nos sistemas de gameplay.
